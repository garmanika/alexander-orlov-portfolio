# Портфолио Александра Орлова

Рабочая первая версия персонального сайта-портфолио по выбранному макету **System**: светлая палитра, чёрная типографика, оранжевый акцент.

## Запуск

```sh
npm run dev
```

Открыть http://127.0.0.1:4173. Сервер доступен только на этом компьютере. Для другого порта задайте переменную окружения `PORT`.

```sh
npm run check
npm test
npm run build
```

Сборка копирует сайт в `dist`. Зависимости для запуска и сборки не требуются; нужен Node.js 14.15 или новее. Никакого серверного приложения, базы данных и сторонних запросов при загрузке страницы нет. Шрифты и изображения локальные.

## Структура

- `src/index.html` — семантическая разметка двух основных экранов и диалогов.
- `src/styles.css` — стили, адаптивная вёрстка и reduced-motion.
- `src/app.mjs` — карусель, клавиатура, свайпы и диалоги.
- `src/projects.mjs` — данные проектов и контакты владельца.
- `src/assets` — локальные фотографии, иллюстрация и шрифты с лицензиями.
- `tests/check.mjs` — проверки данных, ссылок, файлов и границ карусели.
- `tests/browser.cjs` — проверка браузером на 320–1440 px, контактов, диалогов и свайпа.
- `design/implementation` — снимки первой реализации и результат проверки.

Выбран небольшой статический стек вместо React: для двух экранов и карусели фреймворк не добавляет нужных возможностей, но увеличивает зависимости и стоимость сопровождения. Повторяющиеся карточки создаются одной функцией из единого массива проектов.

## Проверка браузером

Нужны Playwright и установленный Google Chrome. В рабочей среде использован готовый runtime без добавления зависимостей в проект:

```powershell
$env:NODE_PATH='C:\Users\Garmanika\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\node_modules'
& 'C:\Users\Garmanika\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe' tests/browser.cjs
```

При этом `npm run dev` должен работать в отдельном терминале. Скрипт открывает изолированный headless-браузер и не использует личную сессию Chrome.
